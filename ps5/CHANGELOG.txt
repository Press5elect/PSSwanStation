PSSwanStation - what changed
============================

Build 17
  Added
  - "What's new" after an update: what changed since the build you had.
  - Card backups sent to the network share, in a folder of each console's.
  - The manual: ps5/MANUAL.md on GitHub.
  Changed
  - Covers on the network share go both ways: a cover set on one console
    is there for the others.
  - A picture larger than the screen is averaged down (8x on 1080p).
  Fixed
  - Sparkles along polygon edges above 1x: gaps between polygons closed
    (Settings, Enhancement; on at first, off in the Speedrun preset).
  - CAS and FSR 1 at large enlargements.
  - Frame generation smeared across a cut; it starts again after a state
    load.
  Works on my console.

Build 16
  Added
  - Sleep-safe saving: the game is saved every five minutes and when the
    PS menu opens; the next start offers to continue.
  - Speedrun timer with splits (by hand or by a value in memory) and bests.
  - Find in memory: cheat search, watch, freeze, make a cheat.
  - Phone and web control (port 3311, QR code to scan).
  - Shader presets (.slangp) from a USB drive, compiled on the console.
  - Debug: recordings of what you press, verbose logging.
  - Picture preset Speedrun (the picture as the PlayStation drew it).
  - Interface up to 140%, high contrast, colour-blind safe colours.
  Changed
  - Texture packs read from PSSwanStation/textures/ on a USB drive (the
    old place still works).
  Fixed
  - SwanStation upstream: video playback fix, fuzzing fixes.
  Run on a PC only so far.

Build 15
  Added
  - Picture: a scaling filter of its own - smooth, square pixels, sharp
    bilinear, FSR 1, NIS and CAS - with one sharpening setting. Picture tube
    adds crt-guest-advanced in five kinds. Video signal: dither smoothed,
    S-Video, composite. Brightness, contrast, colour, gamma. All per game.
  - NFS shares (versions 3 and 4) beside SMB and FTP.
  - Your files on the network share: memory cards shared between consoles,
    covers from the share, or the whole folder; or on a USB drive.
  - Cheats from the libretro database for games chtdb has none for.
  Changed
  - Frame generation: quality (Performance, Balanced, Quality with a
    two-way check), pictures ahead of the game's (no delay), up to 60 at
    120 Hz, videos left out if wanted, one frame of run-ahead, a view of the
    movement, any rate with pacing by the clock. The frame counter shows the
    game's pictures and the screen's.
  Fixed
  - Frame generation: games that never swap their picture are counted by
    whether they drew; uneven cadences are evened out.
  Works on my console; NFS not tried there yet.

Build 14
  - Picture settings can be a game's own: scaling (FSR 1 too), sharpening,
    smooth scaling, picture preset, picture tube, beside the picture, frame
    pacing, black frame insertion, frame generation. Set them in the game's
    details (Options) or, while it runs, in the menu under Game settings,
    Picture; they are remembered for that game. Display output stays one
    setting for every game.
  - Circle in the library asks whether to close PSSwanStation.
  - The cheat and patch database is fetched from its project when asked
    (Settings, Games and network); a release does not carry it.
  The first build published as a release; it ran on a console before that.

Build 13
  - Frame generation smears far less. The title now counts the pictures the
    game really draws (30, 20, 60 a second) and fills only the gaps between
    them; a game that draws 60 at 60 Hz is left alone. A made picture is
    taken from the nearer of the two game pictures, not mixed from both.
  - Frame generation is Off, On, or "On, lighter" (less work for the
    graphics processor). Settings, Picture says what the running game is
    counted at.
  - The Lapy helper is the newer one that ProsperoEden carries (firmware
    13.60 fix).
  Run on a PC only so far.

Build 12
  - Frame generation (Settings, Picture): a picture drawn between each two
    of the game's. Twice the frames at 120 Hz; at 60 Hz, 30 fps games move
    at 60 and PAL games lose their stutter. An experiment.
  - Settings, Interface, "Library view" now lists every view (Flow, Row,
    Wall, Cascade, Wheel and Aurora layouts), as the library's own list does.

Build 11
  - Library: five new views that stand the covers in space, in the manner of
    the Xbox 360's Aurora: Flow, Row, Wall, Cascade, Wheel (Square, View).
    Aurora layout files (.cfljson) in layouts/ are offered too.
  - Scaling: "Fit the screen, FSR 1" enlarges the picture with AMD's FSR 1.
  - Texture packs can stay on a USB drive (psx/textures/<serial>/).
  - Removed: the screenshot shortcut, menu entry and folder (the console's
    Create button does screenshots and video), and "Faster loading" (the
    CD-ROM speedup settings under Console do the same).
  - RetroAchievements is no longer marked as an experiment: it works.
  - The release zip stores every file open to all users, as the console
    wants an app's files.

Build 10
  New. None of it has run on a console yet; the README says what each is.
  - While playing, OPTIONS held with another button: fast forward (R2),
    rewind (L2, kept in memory only), screenshot (Triangle), save and load a
    state (R1, L1). A tap of OPTIONS opens the menu as before.
  - Save states show the picture they were saved at.
  - Picture: presets, picture-tube lines, what is beside a 4:3 picture,
    120 Hz output with black frame insertion, a variable refresh rate.
  - Library: favourites, hidden games, sorting and filters (Square), a
    cover of your choice, the time in the header.
  - Memory card manager: copy, delete, bring in and put out saves; a copy of
    a card is kept whenever it changes.
  - Controllers: button remapping and turbo, tilt steering, player lights,
    neGcon and GunCon.
  - RetroAchievements and two-console netplay, both as experiments.
  - Updater (Menu, Update): fetches a new build and keeps your files.
  - Also: menu music, faster loading, texture packs, waking a sleeping
    server, the newest cheat database, your files outside the title folder,
    safe start (hold L1 and R1 at start), the swan as a screen saver.
  - A controller's battery is not shown: the console offers a title no way
    to read it that I know of.
  Under it: Dear ImGui 1.92, the newest Vulkan driver, SDK and template, and
  the Lapy helper in place of the earlier one for leaving the sandbox.

Build 9
  - Library: L2 and R2 jump to the previous and the next letter.
  - Search: press the touch pad in the library, type a part of the name, and
    the games from the console, USB and the network that match are listed.
  - Menu sounds (Settings, Interface, "Interface sounds" to switch them off).

Build 8
  - Opening Options or Cheats for a network game no longer freezes the
    screen while the share answers.
  - Loading a network game: one progress bar for the whole game, the swan no
    longer jumps back, the text is under the bar with speed and time left.

Build 7
  - The title is now called PSSwanStation.

Build 6
  - Games from an FTP server (a "path = ftp://..." line in network.cfg).
  - Players 2 to 4: other users logged in on the console, picked up while
    the title runs; the multitap is on the Controllers page.

Build 5
  - New start-up animation with sound: the swan takes the lift.

Build 4
  - The library only shows the places (Internal, USB, Network) that have games.

Build 3
  - The swan moves: it flies to its corner, looks about, flies at the screen.

Build 2
  - Start-up screen, a game's details with description, its own options and
    its cheats, disc change from the details, playlists hidden.
